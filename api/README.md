# BY MITYA — сайт + заявки в Telegram

## Что где лежит

```
index.html          сам лендинг (он же by-mitya.html, копия для удобства)
package.json        нужен, чтобы Vercel понимал функции
api/order.js        принимает заявку с сайта → отправляет заказ ботом в чат
api/telegram.js     ловит нажатие «Да ✅» / «Нет ❌» → дописывает статус в сообщение
```

Токена бота нет ни в одном файле — он подставляется из переменных окружения Vercel.

---

## Настройка, 5 шагов

### 1. Перевыпустить токен
Старый токен засветился в переписке, им может воспользоваться посторонний.
@BotFather → `/revoke` → выбрать бота → скопировать новый токен.

### 2. Залить файлы на Vercel
Структура папки должна остаться ровно такой, как выше: `index.html` в корне, функции в папке `api`.

### 3. Прописать переменные окружения
Vercel → проект → **Settings → Environment Variables**. Три штуки:

| Имя | Значение |
|---|---|
| `BOT_TOKEN` | новый токен из BotFather |
| `CHAT_ID` | `-5345314221` |
| `WEBHOOK_SECRET` | любая случайная строка, например `mitya_7f3k9x2p` |

После добавления переменных нажмите **Redeploy** — без этого они не подхватятся.

### 4. Подключить вебхук
Один раз открыть в браузере ссылку, подставив свои значения:

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://<ВАШ-ДОМЕН>.vercel.app/api/telegram&secret_token=<WEBHOOK_SECRET>
```

Должно ответить `{"ok":true,"result":true,...}`. Без этого шага кнопки под заказом работать не будут.

### 5. Проверить
Оформить тестовый заказ на сайте. В чат должно прийти:

```
НОВЫЙ ЗАКАЗ            ← жирным

Имя: Мария
Номер телефона: +375291234567
Telegram: @maria
Город: Минск
Комментарий: Позвонить после 18

ЗАКАЗАЛ(А):            ← жирным
Губы - чёрная - 1 шт
мУтки в Париже - белая - 2 шт

Сумма: 270 BYN

ЗАКАЗ ЗАКРЫТ?
[Да ✅]  [Нет ❌]
```

После нажатия кнопки в конце сообщения появится `Закрыт ✅` или `Закрыт ❌`, а сами кнопки исчезнут.

## Если что-то не работает

**Заявка не уходит, на сайте красная плашка**
Vercel → Deployments → последний деплой → Functions → `api/order` → логи. Частые причины: не нажали Redeploy после добавления переменных; опечатка в имени переменной.

**В логах «chat not found»**
Неверный `CHAT_ID` либо бота выкинули из чата. Проверить id: добавить в чат @getmyid_bot или открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` после любого сообщения в чате. У супергрупп id выглядит как `-100…`.

**Заявки приходят, кнопки не реагируют**
Не выполнен шаг 4, либо `WEBHOOK_SECRET` на Vercel и в ссылке setWebhook отличаются. Проверить: `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo`.

## Полезно знать

- Кнопки **исчезают после первого нажатия**, поэтому статус потом не переправить. Если промахнулись — заказ придётся вести по памяти или переспросить в чате.
- Сумма берётся из корзины на сайте. Если товара в заказе нет или сумма нулевая, строка просто не выводится.
- Корзина очищается только после успешной отправки. Если Telegram недоступен, заказ остаётся в корзине и человек может попробовать ещё раз.
- Функция обрезает слишком длинные поля и не более 30 позиций в заказе — защита от мусорных заявок.
